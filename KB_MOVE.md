## Органы управления

### Пэды (32 штуки) — Pads «пэдз»
Резиновые подушечки 4 ряда × 8. Чувствуют силу удара (velocity) и давление после удара (Polyphonic Aftertouch — у каждого пэда своё).

- Где: Note Mode: в ударных левые 16 — звуки набора, в мелодических все 32 — ноты. Session Mode: каждый пэд — клип (ряд = трек, столбец = сцена). Set Overview: каждый пэд — сет.
- **Пэд** — сыграть ноту или звук
- **Пэд, потом шаг** — поставить ноту на этот шаг
- **Держи шаг + пэд** — добавить или убрать ноту на шаге (так собирают аккорд)
- **Держи пэд + Volume** — громкость сэмпла (Sample Gain)
- **Mute + пэд ударных** — заглушить звук набора
- **Delete + пэд ударных** — стереть все ноты этого звука
- **Shift + пэд в Set Overview** — меню сета: цвет, Upload to Cloud, Make Local
- **Провести пальцем по столбцу (Session)** — запустить сцену
- Ограничения: Channel Aftertouch (общее давление на все пэды) Move не поддерживает. Давление работает только с Drift и Wavetable.
- Метка: официально (MM)

### Шаги (16 кнопок внизу) — Step Buttons «стэп ба́ттнз»
16 кнопок = один такт, каждая — 1/16. Чёрточка под шагами 1, 5, 9, 13 — начало каждой доли. В Loop Mode шаги — это такты клипа.

- Где: Note Mode — шаги нот; Loop Mode — такты; с Shift — меню (значки под шагами).
- **Нажми шаг** — убрать все ноты с шага
- **Держи шаг + Volume** — сила удара ноты
- **Держи шаг + колесо** — длина ноты (щелчок = 10% шага)
- **Держи шаг + ‹ или ›** — сдвиг ноты на 10% шага; долго — на целый шаг
- **Держи шаг + Shift + ‹ ›** — сдвиг на 1% шага
- **Держи шаг + + или −** — транспонировать на полутон; долго — на октаву
- **Держи шаг + ручка** — пошаговая автоматизация
- **Держи шаг + коротко другой шаг** — быстро задать длину ноты (с 1.4)
- **Copy + шаг, потом другой шаг** — копировать ноты шага
- Ограничения: Сетка по умолчанию 1/16. Мельче (1/32, триоли) — Shift + шаг 3 → Step Grid; тогда такт делится на несколько страниц.
- Метка: официально (MM, MR)

### Shift (кнопка «…», справа внизу в правом столбце) — Shift «шифт»
Кнопка второго слоя. Держишь — под шагами загораются значки меню, у других кнопок включается вторая функция.

- Где: Все режимы.
- **Shift + шаг 1** — Set Overview — все сеты
- **Shift + шаг 2** — Setup — Wi-Fi, Update, Cloud, Control Live, Link, MIDI, USB-C Audio, Move Manager, Brightness, Advanced
- **Shift + шаг 3** — Workflow Settings — Quantize, Step Grid, Count-In, Autoload, Max Length (2.0), размер такта (2.1)
- **Shift + шаг 5** — Tempo
- **Shift + шаг 6** — Metronome вкл/выкл
- **Shift + шаг 7** — Groove (свинг)
- **Shift + шаг 8** — 16 Pitches (ударные по нотам)
- **Shift + шаг 9** — Keys & Scales
- **Shift + шаг 10** — Full Velocity
- **Shift + шаг 11** — Repeat / Arp
- **Shift + шаг 14** — New Clip
- **Shift + шаг 15** — Double Loop
- **Shift + шаг 16** — Quantize
- **Shift + шаг 16 + пэд** — квантовать один звук ударных (с 1.4)
- **Shift + Play** — перезапустить все клипы с начала
- **Shift + Undo** — Redo — вернуть отменённое
- **Shift + Capture** — очистить то, что Move «запомнил»
- **Shift + Mute + трек** — Solo
- **Shift + кнопка трека** — цвет трека, MIDI In / MIDI Out трека
- **Shift + колесо (на Drift)** — банки параметров Drift
- **Shift + нажать колесо (на сэмпле)** — Sample Options: Slice, Reverse
- **Shift + ручка** — точная настройка
- **Двойное нажатие Shift** — зафиксировать Shift (по схеме на коробке Move)
- Ограничения: Шаги 4, 12, 13 с Shift в мануале не описаны.
- Метка: официально (MM, MR)

### Колесо (большое слева) — Wheel «уи́л»
Крутится, нажимается и чувствует касание. Крутить — листать и менять значения; нажать — выбрать; коснуться — показать текущее.

- Где: Все режимы.
- **Крутить** — листать пресеты, меню, значения
- **Нажать** — выбрать / подтвердить
- **Shift + крутить** — точнее (темп, свинг)
- **Держи шаг + крутить** — длина ноты
- **Держи Loop + крутить** — длина клипа; с Shift — точнее
- **Крутить в Device View** — выбрать пресет трека, инструмент или эффект
- Ограничения: —
- Метка: официально (MM)

### Экран — Display «дисплэ́й»
Белый OLED 128 × 64. Показывает пресет, параметр ручки, меню, темп. На корпусе нет надписей — подсказывает экран.

- Где: —

- Ограничения: Яркость экрана настройкой Brightness не меняется (она для пэдов и кнопок).
- Метка: официально (MM)

### Ручки 1–8 (над пэдами) — Encoders «энко́удэрз»
8 бесконечных сенсорных ручек. Меняют параметры выбранного устройства. Коснулся — на экране имя и значение.

- Где: Note Mode — параметры инструмента или эффекта; Session Mode — 2 общих эффекта сета; Slicing — начало и конец области, начало среза.
- **Коснуться** — показать параметр
- **Крутить** — менять
- **Shift + крутить** — точнее
- **Record + крутить** — записать автоматизацию
- **Держи шаг + крутить** — автоматизация на одном шаге
- **Mute + коснуться** — выключить / включить автоматизацию
- **Delete + коснуться** — удалить автоматизацию
- **Держи Mute и смотри** — огоньки под ручками: нет — пусто, красный — автоматизация есть, белый — выключена
- **Shift + коснуться (на некоторых)** — второй параметр той же ручки, например Decay → Length
- Ограничения: Автоматизировать можно одно устройство за раз. Ручки с замком и зелёным огоньком на Drift заняты макросом — их не крутят (так же в Live).
- Метка: официально (MM, MR)

### Громкость (ручка справа вверху) — Volume encoder «во́льюм»
Девятая ручка. Одна крутит общую громкость, а с зажатыми кнопками — громкость трека, пэда, сета и силу ноты.

- Где: Все.
- **Крутить** — общая громкость выхода
- **Держи трек + крутить** — громкость трека (в дБ)
- **Держи шаг + крутить** — сила удара ноты (velocity)
- **Держи пэд + крутить** — громкость сэмпла (Sample Gain)
- **В Set Overview: держи пэд сета + крутить** — громкость всего сета
- **Loop Mode: держи такт + крутить** — сила всех нот такта
- Ограничения: Без игры менять можно, но не услышишь.
- Метка: официально (MM)

### Кнопки треков (4 полоски слева от пэдов) — Track Buttons «трэк ба́ттнз»
Выбор трека 1–4. Полоска светится цветом трека; во время игры белеет на громких местах.

- Где: Note и Session.
- **Нажать** — выбрать трек и открыть Device View
- **Подержать невыбранный** — подсмотреть трек, не переключаясь
- **Держи трек + Volume** — громкость трека
- **Mute + трек** — заглушить / включить
- **Shift + Mute + трек** — Solo (полоска синяя)
- **Shift + трек** — цвет и MIDI-каналы трека
- Ограничения: Только 4 трека. Из сетов Note с 8 дорожками на Move открываются первые 4.
- Метка: официально (MM, MR)

### Переключатель Note/Session (значок ☰ слева) — Note/Session Toggle «ноут / сэ́шн»
Переключает Note Mode (играть и программировать) и Session Mode (клипы и сцены).

- Где: —
- **Нажать** — сменить режим
- **Подержать** — подсмотреть другой режим
- **В Set Overview** — сразу в Session выбранного сета
- Ограничения: Записывать ноты можно только в Note Mode.
- Метка: официально (MM)

### Back (стрелка ‹ слева) — Back «бэк»
Выйти на шаг назад из меню, браузера, Sampling Mode.

- Где: Все.
- **Нажать** — назад на уровень
- **Подержать** — выйти из меню совсем
- **В Set Overview** — вернуться в прошлый режим
- Ограничения: —
- Метка: официально (MM)

### Play (▶ слева внизу) — Play «плэй»
Старт / стоп.

- Где: Все.
- **Нажать** — старт или стоп
- **Shift + Play** — перезапустить играющие клипы с начала (эффект «заикания»)
- **В Set Overview: пэд сета + Play** — прослушать сет
- Ограничения: —
- Метка: официально (MM)

### Record (● рядом с Play) — Record «рэ́корд»
Запись нот и движений ручек. Мигает — отсчёт, горит красным — запись, тускло — можно писать.

- Где: Только Note Mode.
- **Нажать** — запись с отсчётом в 1 такт
- **Нажать ещё раз** — стоп записи, музыка играет дальше
- **Record + крутить ручку** — запись автоматизации
- Ограничения: Если остановить запись в первой половине последнего такта, этот такт не войдёт в клип.
- Метка: официально (MM)

### Capture (квадрат в правом столбце, верх слева) — Capture «кэ́пчер»
Move всё время «слушает» твою игру. Нажал Capture — сыгранное становится клипом. Если музыка стояла, Move угадает темп и даст три варианта.

- Где: Note Mode.
- **Нажать** — превратить сыгранное в клип
- **Shift + Capture** — забыть сыгранное
- **Покрутил ручки + Capture** — поймать и автоматизацию
- Ограничения: Темп угадывается только при остановленной музыке. Капчер считает, что первая нота — начало клипа.
- Метка: официально (MM)

### Sampling (● в правом столбце, верх справа) — Sampling «сэ́мплинг»
Вход в Sampling Mode: запись звука сразу на пэд. Источник: Mic, Line in, Line in - Mono (2.1), Resampling, USB-C.

- Где: Note Mode.
- **Sampling → пэд** — начать запись, пэд ещё раз — стоп
- **Держи пэд** — запись пока держишь
- **Коснуться колеса** — показать источник
- **Нажать колесо** — сменить источник
- **Пэд, потом другой пэд (ударные)** — один длинный сэмпл на несколько пэдов с разными стартами
- Ограничения: До 240 секунд за раз. 44,1 кГц, 16 бит. Линейный вход — только линейный уровень (микрофону и гитаре нужен предусилитель).
- Метка: официально (MM, MR, HF)

### Loop (стрелка-петля, второй ряд слева) — Loop «луп»
Loop Mode: шаги показывают такты клипа (до 16).

- Где: Note Mode.
- **Нажать** — войти в Loop Mode
- **Нажать два шага сразу** — длина клипа от и до
- **Дважды нажать шаг** — клип длиной 1 такт
- **Держи Loop + колесо** — длина клипа
- **Держи такт + колесо / Volume / + − / ‹ ›** — длина, сила, высота, сдвиг всех нот такта
- **Delete + такт** — стереть ноты такта
- Ограничения: Клип до 16 тактов.
- Метка: официально (MM)

### Mute (буква M) — Mute «мьют»
Заглушить трек или звук набора.

- Где: Note и Session.
- **Нажать (Note Mode)** — заглушить выбранный трек
- **Mute + трек** — заглушить трек
- **Mute + пэд ударных** — заглушить звук
- **Shift + Mute + трек** — Solo
- **Mute + коснуться ручки** — выключить автоматизацию
- Ограничения: —
- Метка: официально (MM)

### Delete (крестик ×) — Delete «дили́т»
Удаление.

- Где: Все.
- **Нажать (Note Mode)** — удалить играющий клип трека
- **Delete + пэд в Session** — удалить клип
- **Delete + пэд ударных** — стереть все ноты звука
- **Delete + коснуться ручки** — удалить автоматизацию
- **Delete + пэд в Set Overview** — удалить сет (нажать пэд ещё раз — подтвердить)
- **Delete + такт (Loop Mode)** — стереть ноты такта
- Ограничения: Удалённый сет не восстановить. Undo помогает только внутри сета.
- Метка: официально (MM)

### Copy (два квадрата) — Copy «ко́пи»
Копирование: сеты, клипы, ноты, такты. С 2.1 — и Bounce: клип → аудио.

- Где: Все.
- **Нажать (Note Mode)** — дублировать клип, копия станет выбранной
- **Copy + пэд клипа, потом пустой пэд (Session)** — скопировать клип
- **Copy + MIDI-клип → вставить в аудиослот или на пэд** — Bounce: превратить в звук (2.1)
- **Copy + аудиоклип → Shift + вставить в аудиослот** — Bounce аудиоклипа (2.1)
- **Copy + шаг, потом шаг** — копировать ноты
- **Copy + пэд сета, потом пэд** — копировать сет
- **Copy ещё раз** — очистить буфер
- Ограничения: Bounce — один клип за раз.
- Метка: официально (MM, MR)

### Undo (стрелка-возврат) — Undo «анду́»
Отменить последнее действие.

- Где: Все.
- **Нажать** — отменить
- **Shift + Undo** — Redo — вернуть
- **После загрузки пресета** — вернуть прошлый звук
- **После Slice** — вернуть исходный набор
- Ограничения: —
- Метка: официально (MM)

### Кнопки + и − (справа внизу) — Plus / Minus «плас / ма́йнус»
Сдвиг октавы на мелодических треках и в 16 Pitches; с зажатым шагом — транспонирование нот.

- Где: Note и Loop Mode.
- **+ или −** — октава выше / ниже (пэды)
- **Держи шаг + +/−** — нота на полутон
- **Держи шаг + долго +/−** — нота на октаву
- **Loop Mode: держи такт + +/−** — все ноты такта
- Ограничения: —
- Метка: официально (MM)

### Стрелки ‹ и › — Left / Right Arrow «лэфт / райт»
Листать такты клипа; с зажатым шагом — сдвигать ноты.

- Где: Note и Loop Mode.
- **‹ ›** — предыдущий / следующий такт (страница шагов)
- **Держи шаг + ‹ ›** — сдвиг ноты на 10% шага
- **Долго** — на целый шаг
- **+ Shift** — на 1%
- Ограничения: —
- Метка: официально (MM)

### Встроенный микрофон (дырочка справа от ручки 8) — Built-in microphone «ма́йк»
Для сэмплинга. С 2.1 пишет моно.

- Где: Sampling Mode.

- Ограничения: Если что-то подключено к Audio In, вместо микрофона доступен Line in.
- Метка: официально (MM, MR)

### Кнопка питания (жёлтая, сзади) — Power Button «па́уэр»
Включить. Выключить: нажать, потом нажать колесо (Back — отмена).

- Где: —
- **Нажать** — включить
- **Нажать + колесо** — выключить с сохранением
- **Держать 10 секунд** — принудительно выключить (мануал); справка пишет 8 секунд
- **Держать 10 секунд на выключенном** — тест питания: первая полоска трека горит зелёным — питание есть (справка)
- **Держать 18 секунд** — сброс контроллера питания (справка)
- Ограничения: —
- Метка: официально (MM, HP)

### Выход 3,5 мм — Audio Output «о́дио а́утпут»
Наушники или колонки. Встроенный динамик — моно.

- Где: —

- Ограничения: Стерео слышно только в наушниках или колонках.
- Метка: официально (MM, HF)

### Вход 3,5 мм — Audio Input «о́дио и́нпут»
Линейный вход для сэмплинга.

- Где: Sampling.

- Ограничения: Только линейный уровень. Микрофон или гитару — через предусилитель.
- Метка: официально (MM, HF)

### USB-A — USB-A «ю-эс-би эй»
Одна MIDI-клавиатура или контроллер (до 500 мА).

- Где: —

- Ограничения: Только MIDI. Не для компьютера, не для звука, не для другого Move.
- Метка: официально (MM, HM)

### USB-C — USB-C «ю-эс-би си»
Зарядка, Move Manager по кабелю, аудиоинтерфейс, Control Live Mode, MIDI с компьютером или iPhone (с 1.7), сэмплинг с телефона.

- Где: —

- Ограничения: Компьютер должен давать не меньше 7,5 Вт, чтобы Move заряжался.
- Метка: официально (MM, MR)

## Подсветка (сверь на своём Move)
- Шаг белый — на шаге есть нота
- Шаг тусклый цвета трека — пустой шаг
- Шаг тусклый серый — клип пуст или такт вне лупа
- Шаг зелёный — здесь сейчас играет
- Пэд цвета трека (мелодия) — тоника лада
- Пэд светло-серый (мелодия) — нота лада
- Пэд не горит (Chromatic) — нота вне лада
- Пэд белый, когда держишь шаг — ноты этого шага
- Пэды розовые — включён Sampling Mode
- Пэд мигает красным — идёт запись сэмпла
- Session: пэд цвета трека — клип есть
- Session: пэд мигает белым — выбранный клип
- Session: пэд мигает зелёным — клип ждёт начала такта
- Session: пэд мигает цветом трека — клип скоро остановится
- Ударные: пэд тускло-белый — звук заглушён (Mute)
- Полоска трека синяя — Solo
- Полоска трека белеет при игре — громкий сигнал трека
- Огонёк ручки красный — запись автоматизации или автоматизация есть
- Огонёк ручки зелёный + замок (Drift) — параметр занят макросом
- Все пэды пульсируют — листаешь пресеты треков
- Все огоньки ручек пульсируют — листаешь эффекты

## Основы и подключение
- **Включение.** Жёлтая кнопка сзади. Первый запуск — короткое обучение: Wi-Fi, отчёты об ошибках, обновление. Можно пропустить (Skip колесом). Потом — Set Overview с 4 демо-сетами. _(официально; MM)_
- **Батарея.** До 4 часов музыки. Уровень: Shift + шаг 2 → Battery. Села батарея — Move сам сохранит сет и выключится. Заряжай от комплектного блока; от компьютера — если тот даёт 7,5 Вт и больше. _(официально; MM, HF)_
- **Wi-Fi.** Shift + шаг 2 → Wi-Fi → Wi-Fi On → выбери сеть → пароль колесом (Shift — заглавные; «…» слева от пробела — цифры и знаки; галочка справа внизу — готово). Пароль лучше только из латиницы и цифр (ASCII). _(официально; MM, HN)_
- **Обновление.** Shift + шаг 2 → Update → Install → нажми колесо. Или в Move Manager → Settings → Update Now (по USB-C Wi-Fi не нужен). _(официально; MM)_
- **Move Manager.** Сайт внутри Move. В браузере открой move.local/ (с косой чертой). На экране Move появится код — введи его. Если Move несколько, имена будут move-2.local/ и т. п.: Shift + шаг 2 → Move Manager → How to access? _(официально; MM, HG)_
- **Три режима.** Set Overview (все сеты, Shift + шаг 1), Note Mode (играть и программировать трек), Session Mode (клипы и сцены, переключатель ☰). _(официально; MM)_
- **Яркость.** Shift + шаг 2 → Brightness: в мануале — четыре уровня (среди них Max, High, Mid); с 1.7 добавили ещё более тусклые Dim и Min. Экран это не меняет. Низкая яркость бережёт батарею — совет из сообщества. _(официально; MR, IS)_

## Пэды и звуки
- **Пресет трека.** Каждый трек = один инструмент + два эффекта (Track Preset). Новый сет получает случайные: трек 1 — ударные, 2 — бас, 3 — пэд/клавиши/пиццикато/ритмический, 4 — лид или духовые. _(официально; MM)_
- **Сменить звук.** Нажми трек → колесом выдели пресет (подсвечены все значки) → нажми колесо → браузер. Крути — звук меняется сразу (Autoload). Undo — вернуть прошлый. _(официально; MM)_
- **Сохранить свой звук.** Выдели пресет → нажми колесо → держи Shift → Options → Save Preset. Лежит в User Presets. _(официально; MM)_
- **Шаблоны.** Templates: Analog… (Drift), FM… и WT… (Wavetable), Sampler (пустой Melodic Sampler), Drum Kit, Choke Kit (новый звук обрывает прошлый), Gate Kit (звук играет, пока держишь), Drift Default без макросов (1.7). _(официально; MM, MR)_
- **Сила удара.** Пэды чувствуют силу. Все ноты на максимуме: Shift + шаг 10 (Full Velocity). _(официально; MM)_
- **16 Pitches.** Ударные: Shift + шаг 8 → правые 16 пэдов играют выбранный звук по нотам. + и − — октава. Move считает, что любой сэмпл звучит как до (C). _(официально; MM)_

## Сэмплы и запись
- **Запись на пэд.** Выбери трек → Sampling → нажми пэд (старт) → нажми ещё раз (стоп). Или держи пэд, пока пишешь. До 240 с. _(официально; MM)_
- **Источник.** Коснись колеса — видно источник. Нажми колесо — смени: Mic (или Line in, если вставлен кабель), Line in - Mono (2.1), Resampling (общий выход Move), USB-C (звук с компьютера или телефона). _(официально; MM, MR)_
- **Громкость входа.** В Sampling Mode колесом выбери значок уровней → нажми → крути Gain. _(официально; MM)_
- **Нарезка (Slice).** Сэмпл на экране → Shift + нажать колесо → Slice. Колесо — число срезов; ручки 1 и 2 — начало и конец области; нажми пэд среза и ручкой 3 двигай его начало. Колесо или Back — готово (новый Drum Rack). Undo — отменить. _(официально; MM)_
- **Разворот (Reverse).** Значок сэмпла → Shift + нажать колесо → Reverse (с 1.6). _(официально; MR)_
- **Свои файлы.** Move Manager → Samples → Upload: WAV, AIF, AIFF до 100 МБ. На Move — папка User Samples. Записанное на Move — User Recordings. _(официально; MM)_
- **Аудиотрек (2.0).** Выдели пресет трека → колесо → Back до верхнего уровня → в самом верху Audio Track. Звук держится в темпе (варпинг). Можно пропускать живой вход через эффекты трека. _(официально; MR)_

## Ритм и секвенсор
- **Поставить ноту.** Нажми пэд, потом шаг. Или держи шаг и нажми пэд. Убрать — нажми шаг. _(официально; MM)_
- **Сетка и размер.** Shift + шаг 3 → Step Grid (1/16 по умолчанию; 1/32 и триоли — на нескольких страницах), Quantize (сила квантования), Count-In, Autoload, Max Length (2.0), размер такта (2.1). _(официально; MM, MR)_
- **Свинг.** Shift + шаг 7 → Groove: 0% ровно, 100% — идеальный триольный свинг 1/16, больше 100% — утрировано. Действует на весь сет. _(официально; MM)_
- **Повтор и арпеджио.** Shift + шаг 11. Ударные: колесом скорость повтора. Мелодия: Repeat, Arp Up, Arp Down, Arp Random и Rate. Выйти — снова Shift + шаг 11. _(официально; MM)_
- **Квантовать.** Shift + шаг 16 — весь клип; Shift + шаг 16 + пэд — один звук. _(официально; MM, MR)_
- **Длина клипа.** Loop → нажми два шага (от и до); дважды один шаг — 1 такт; или держи Loop и крути колесо. Shift + шаг 15 — удвоить луп с нотами. _(официально; MM)_
- **Разная длина клипов.** Клипы на разных треках могут быть разной длины: 1 такт ударных под 4 такта баса — это нормально и полезно. _(сообщество; IS, CD)_

## Мелодия и гармония
- **Лад.** Shift + шаг 9 → Keys & Scales: In-Key (только ноты лада) или Chromatic (все); Octaves (ряд = октава) или 4ths (вверх — кварта); тоника (Key) и лад (Scale). Выйти — Back. _(официально; MM)_
- **Где какая нота.** In-Key, Octaves: нижний ряд — от тоники вверх по ладу, следующий ряд — октавой выше. Тоника горит цветом трека, остальные — светло-серым. _(официально; MM)_
- **Октавы.** + и − сдвигают весь диапазон пэдов на октаву. Для баса нажми − один-два раза. _(официально; MM)_
- **Аккорд.** Нажми сразу 3 пэда (например, 1-й, 3-й и 5-й пэд нижнего ряда в In-Key — это трезвучие) и нажми шаг. Держи шаг и нажимай пэды — добавляешь или убираешь ноты аккорда. _(официально; MM)_
- **Важно.** Смена лада не двигает уже записанные ноты — меняются только пэды. _(официально; MM)_
- **Отдельного режима аккордов нет.** В мануале Move нет кнопки «аккорд одним пальцем». Аккорд играется несколькими пальцами. _(официально; MM)_

## Ручки и автоматизация
- **Что крутят ручки.** В Device View колесом выбираешь: весь пресет, инструмент, сэмпл или эффект. Ручки 1–8 крутят параметры выбранного. Коснись — увидишь имя. _(официально; MM)_
- **Банки параметров.** Drum Sampler: Main Bank и Filter & Setup. Melodic Sampler: Main Bank и Setup. Переключить: выдели сэмпл → держи Shift → крути колесо (с 1.5). Drift: выдели пресет → держи Shift → крути колесо по часовой (с 1.7). _(официально; MM, MR)_
- **Записать движение.** Record + крути ручку (огонёк красный). Или крути при игре и нажми Capture. _(официально; MM)_
- **На одном шаге.** Держи шаг с нотой + крути ручку — параметр меняется до следующей ноты (шаги краснеют). _(официально; MM)_
- **Выключить и удалить.** Mute + коснуться ручки — выключить; Delete + коснуться — удалить. _(официально; MM)_
- **Перебить на ходу.** Крути ручку поверх записанного движения — пока держишь, звучит твоё; отпустил — вернулась запись. _(официально; MM)_

## Сеты и проекты
- **32 сета.** Set Overview: каждый пэд — ячейка. Пустой пэд + кнопка трека — новый сет. Автосохранение — через 10 с без действий, при входе в Set Overview и при выключении. _(официально; MM, HF)_
- **Копия и удаление.** Copy + пэд сета → пэд-цель. Delete + пэд → ещё раз пэд (не отменить). _(официально; MM)_
- **Цвет и облако.** Shift + пэд сета: Color, Upload to Cloud, Make Local. _(официально; MM)_
- **Экспорт.** Move Manager → Sets → три точки → Export as Audio → WAV или MP3. Играет все клипы слева направо — для трека сделай копию сета без лишних клипов. _(официально; MM)_
- **Загрузка сетов на Move.** С 1.6 сеты Move и Note можно загрузить на Move через Move Manager → Sets → Upload. _(официально; MR)_

## Wi-Fi и синхронизация с Live
- **Ableton Cloud.** Включается в Move Manager → Settings → Activate Cloud. Хранит до 8 сетов для Move, Note, Live и Push. Нужен Wi-Fi. _(официально; MM)_
- **Открыть в Live.** Скачай .ablbundle из Move Manager → двойной щелчок. Live 12.4+ нужен для сетов Move 2.0 и новее. Drum Sampler есть в Live 12.1+, в старых версиях он станет Simpler и может звучать иначе. _(официально; MM, MR)_
- **Chrome блокирует скачивание.** Chrome пишет «Insecure download blocked» из-за адреса .local — нажми Keep. Или Safari / Edge. Ошибку Safari с .zip исправили в 2.1.1. _(официально; MM, HG, MR)_
- **Link.** Shift + шаг 2 → Link: Off, Tempo, Start/Stop. Первое устройство в сессии задаёт темп. С Link не работает отсчёт перед записью. _(официально; MM)_
- **Link Audio (2.0).** Move отправляет звук общего выхода или отдельных треков в аудиодорожки Live. Включи Link на Move, Link и Link Audio в Live. Лучше по USB-C, по Wi-Fi качество зависит от сети. _(официально; MR)_
- **Аудиоинтерфейс.** По USB-C Move — звуковая карта для Live (44,1 кГц; при другой частоте в Live звука не будет). Shift + шаг 2 → USB-C Audio: Mic или Main Out (с Main Out динамик выключается). _(официально; MM)_
- **Control Live Mode.** Move как пульт для Live 12.1+ (или 11.3.35+). Shift + шаг 2 → Control Live, кабель USB-C. Не работают: 16 Pitches, Arpeggiator, захват автоматизации, Sampling Mode, MIDI через USB-A. _(официально; MM, HL)_

## Расширенные приёмы
- **Bounce (2.1).** Session: Copy + MIDI-клип → нажми аудиослот или пэд ударных. Клип станет звуком. Отмена — нажми колесо, пока идёт полоска. Файлы — в папке Bounces. _(официально; MR, MB)_
- **Ресэмплинг.** Sampling → источник Resampling → пэд. Запишет всё, что звучит, со всеми эффектами. Если музыка стояла — запуск совпадёт с началом записи. _(официально; MM)_
- **Один сэмпл на много пэдов.** Sampling на ударных: пэд → во время записи другой пэд → ещё… Каждый пэд получит тот же звук с разного места. _(официально; MM)_
- **Перезапуск клипов.** Shift + Play во время игры — всё с начала. Повторяй ритмично — «заикание». _(официально; MM)_
- **MIDI с компьютером и iPhone (1.7).** Move в обычном режиме по USB-C виден как MIDI-устройство. Каналы трека: Shift + трек → MIDI In / MIDI Out. Синхронизация: Shift + шаг 2 → MIDI Sync (Off / In / Out); при In выключи Link. _(официально; MR, HM)_
- **Variations в ударные.** Пользователи бонсят разные варианты клипа прямо в пэды набора и собирают из них новый ритм. _(сообщество; EL)_
- **Сторонние прошивки (Schwung и т. п.).** На Elektronauts обсуждают самодельные синты и эффекты для Move. Это неофициально, может сломать сеты и гарантию; часть пользователей удалила из-за ошибок. Для учёбы не нужно. _(сообщество; EL)_

## Частые проблемы

### Нет звука
1. Покрути Volume (правая верхняя ручка) — это общая громкость.
2. Проверь, не заглушён ли трек: держи Mute — тусклые полоски заглушены.
3. Если подключены наушники — звук идёт в них, а не в динамик.
4. USB-C Audio = Main Out выключает динамик: Shift + шаг 2 → USB-C Audio → Mic.
_(официально; MM)_

### Move не выключается
1. Нажми питание, потом колесо.
2. Не помогло — держи питание 10 секунд (мануал) или 8 секунд (справка).
_(официально; MM, HP)_

### Move не включается
1. Подключи родной блок питания на несколько минут.
2. Держи питание 8 с (выключить), потом 10 с: первая полоска трека зелёная — питание есть.
3. Держи 18 с — сброс контроллера питания; отпусти, когда погаснет зелёный, и включи.
4. Не помогло — техподдержка Ableton.
_(официально; HP)_

### Не подключается Wi-Fi
1. Shift + шаг 2 → Wi-Fi → выключи и включи.
2. Пароль только из латиницы и цифр.
3. Перезапусти роутер (некоторые после неверного пароля не пускают).
4. Выключи VPN.
_(официально; HN)_

### Не открывается move.local
1. Пиши с косой чертой: move.local/
2. Move и компьютер — в одной сети.
3. Посмотри точный адрес: Shift + шаг 2 → Move Manager → How to access?
4. По кабелю: выключи Wi-Fi на Move и открой http://172.16.254.1
5. Другой браузер; на Windows с VPN — ipconfig /flushdns.
_(официально; HN, HG)_

### Сет скачивается как .zip
1. Это ошибка Safari, исправлена в Move 2.1.1 — обнови Move.
_(официально; MR)_

### Chrome не даёт скачать сет
1. Нажми значок загрузок справа сверху → Keep у файла.
2. Или скачай в Safari.
_(официально; MM, HG)_

### Сет звучит в Live иначе
1. Нужен Live 12.4+ для сетов Move 2.0 и новее.
2. В Live ниже 12.1 Drum Sampler превращается в Simpler — эффекты воспроизведения пропадут.
_(официально; MM, MR)_

### Live не видит Move как пульт
1. Обнови Live.
2. Кабель плотно; попробуй другой.
3. На Move: Shift + шаг 2 → должно быть Control Live.
4. Отключи кабель, подожди 5 секунд, подключи.
_(официально; HL)_

### Mac не видит MIDI-порты Move
1. Отключи Move.
2. Finder → Программы → Утилиты → «Настройка Audio MIDI» → Окно → MIDI-студия → удали «Ableton Move».
3. Подключи снова и разреши аксессуар, если macOS спросит.
_(официально; MR, HM)_

### После сна Mac порты Move пропали
1. Переподключи кабель.
2. Разреши подключение аксессуара в окне macOS.
_(проверено мной; ME)_

### Гудит и шумит при подключении к компьютеру
1. Это «земляная петля».
2. Помогает USB-изолятор или аудиотрансформатор (модели — в справке Ableton).
3. Проверь на батарее без кабеля — шум уйдёт, значит, дело в петле.
_(официально; HI)_

### В Live нет звука с Move по USB
1. В Live выбери Move как вход (Audio Input Device).
2. Частота в Live — 44 100 Гц, иначе звука не будет.
3. Shift + шаг 2 → USB-C Audio → Main Out, если нужен общий выход.
_(официально; MM)_

### iPhone не играет в свой динамик, когда подключён Move
1. Ограничение iOS 18.
2. Выбери Move как выход, или подключи наушники к iPhone, или на Move: Sampling → USB-C → Monitoring On.
_(официально; HF)_

### Ноты лада не те после смены лада
1. Так задумано: смена лада не двигает записанные ноты. Транспонируй вручную: держи шаги + + или −.
_(официально; MM)_

### Сэмпл в 16 Pitches звучит не в той ноте
1. Move считает каждый сэмпл нотой до. Подстрой Transpose сэмпла (ручка 1 в Main Bank).
_(официально; MM)_

### Сет не загружается: мало памяти
1. На сет — до 800 МБ сэмплов (16-битные файлы в памяти занимают вдвое больше).
2. Убери длинные сэмплы или сделай Bounce и удали лишнее.
_(официально; MR)_

## Честные ограничения
- **Пэды и кнопки Move не уходят по MIDI в обычном режиме.** В твоём тесте по портам Live и User пришло только касание ручки громкости (note 8, CC 79) и одно служебное sysex-сообщение. Пэды и кнопки не появились. Справка Ableton тоже пишет: MIDI CC Move отдаёт только в Control Live Mode. Что делать: Играть нотами на компьютер можно с трека, у которого включён MIDI Out (Shift + трек). Полный пульт — Control Live Mode с Live. _(проверено мной; ME, HM)_
- **Подсвечивать пэды Move с компьютера нельзя.** Открытого способа управлять огнями Move нет — его не описывают ни мануал, ни справка. В твоём тесте ответа от пэдов не было. Что делать: Пособие показывает подсветку на своей схеме Move. _(проверено мной; ME)_
- **Порт Standalone присылает только клок и старт/стоп.** В твоём тесте в обычном режиме порт Standalone отдавал MIDI Clock и Start/Stop. Ноты он передаёт, если на треке включён MIDI Out (по справке). Что делать: Shift + трек → MIDI Out → канал. _(проверено мной; ME, HM)_
- **4 трека.** Экономия процессора и батареи, мгновенный отклик. Что делать: Bounce (2.1), ресэмплинг, 16 Pitches (до 16 высот одного звука). _(официально; MM, IV)_
- **Клип до 16 тактов.** Так устроен Loop Mode. Что делать: Длинную партию дели на несколько клипов и сцен. _(официально; MM)_
- **Нет окна аранжировки.** Move — блокнот идей, аранжировку доводят в Live. Что делать: Сцены по порядку + экспорт; или перенос в Live. _(официально; MM)_
- **Нет Return и сайдчейна.** В мануале нет. Что делать: Посыл пэда на эффект набора (Drum Rack); Auto Pan-Tremolo в режиме тремоло под темп как «качание». _(официально; MM)_
- **Нет MIDI CC и MIDI-маппинга.** Официальное ограничение. Что делать: Крути ручки Move руками или пиши автоматизацию. _(официально; HM, HF)_
- **Живые наборы (Live Packs) не ставятся.** Официальное ограничение. Что делать: Отдельные сэмплы из паков можно загрузить через Move Manager. _(официально; MM)_
- **Сеты Live на Move не открываются.** Путь только Move → Live. Что делать: — _(официально; HF)_
- **Только 44,1 кГц.** Официальное ограничение. Что делать: В Live выбери 44 100 Гц, когда Move — звуковая карта. _(официально; HF, MM)_

## Лайфхаки
- **Темп угадает Capture.** Останови музыку, сыграй ритм пальцами и нажми Capture — Move предложит три темпа. Крути колесо, если угадал не тот. _(официально; MM)_
- **Подсмотреть трек, не переключаясь.** Подержи кнопку чужого трека. _(официально; MM)_
- **Подсмотреть другой режим.** Подержи переключатель ☰. _(официально; MM)_
- **Быстрая длина ноты.** Держи шаг и коротко нажми шаг, где нота должна закончиться (с 1.4). _(официально; MR)_
- **Тонкий сдвиг ноты.** Держи шаг + Shift + стрелка — сдвиг на 1% шага: «живая» игра мимо сетки. _(официально; MM, IS)_
- **Обрезать хвост открытого хэта.** Choke у обоих хэтов (Filter & Setup, ручка 5) — закрытый обрывает открытый. _(официально; MM)_
- **Видео без мерцания.** Shift + шаг 2 → Advanced → Refresh Rate (60, 90, 96, 100 Гц; по умолчанию 90). _(официально; MR, HF)_
- **Скрытая страница логов.** move.local/advanced — журналы для техподдержки. _(официально; MM)_
- **Экранный диктор.** move.local/screen-reader — экспериментальная страница для незрячих (появилась в 1.1). _(сообщество; CD)_

## Где источники спорят
- **Сколько держать питание для принудительного выключения.** ① Мануал: 10 секунд. ② Справка «Move does not turn off or on»: 8 секунд. Как быть: Держи 10 секунд — сработает в обоих случаях.
- **Память под сэмплы.** ① Мануал: 400 МБ на сет. ② Примечания 1.8.0: до 800 МБ. Как быть: Верно 800 МБ — примечания новее, мануал не обновили.
- **Сохранить пресет.** ① Мануал: колесо → держи Shift → Options → Save Preset. ② Isotonik: «Shift + Save». Кнопки Save на Move нет. Как быть: Делай по мануалу.
- **Октава для выбранных нот.** ① Мануал: держи шаг + долго нажми + или −. ② Isotonik: «Shift + вверх/вниз». Как быть: По мануалу — долгое нажатие. Вариант с Shift не проверен.
- **Есть ли нарезка (slicing).** ① cdm.link (прошивка 1.x): нарезки нет. ② Примечания 1.5.0 и мануал: Slice есть. Как быть: Есть, с 1.5. Статья cdm.link устарела.
- **MIDI в обе стороны.** ① cdm.link (1.x): только вход или только выход. ② Примечания 1.5.0: вход и выход одновременно; с 1.7 — и по USB-C. Как быть: Сейчас — в обе стороны.
- **Channel Aftertouch.** ① Мануал и Technical FAQ: не поддерживается. ② Справка Using MIDI with Move в одном месте перечисляет его в поддерживаемых. Как быть: Считай, что не поддерживается.
- **Версия прошивки.** ① Старые копии страниц: 2.0.5. ② ableton.com на 25.10.2026: стабильная 2.1.1, бета 2.1.5b2. Как быть: Верно 2.1.1 / 2.1.5b2.
